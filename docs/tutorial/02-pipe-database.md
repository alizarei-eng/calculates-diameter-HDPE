# درس ۰۲ — بانک ابعاد لوله

## هدف

یاد می‌گیریم چگونه ابعاد ثبت‌شده یک لوله را بازیابی و قطر داخلی اسمی را محاسبه کنیم.

## داده موجود

نسخه فعلی بانک شامل ۲۲ رکورد PE100 SDR11 با OD اسمی ۳۲ تا ۶۳۰ میلی‌متر است. این داده یک مجموعه اولیه است و جایگزین نسخه کنترل‌شده استاندارد جاری یا دیتاشیت سازنده نیست.

## منطق قطر داخلی اسمی

اگر OD و ضخامت اسمی دیواره را داشته باشیم:

`ID_nominal = OD_nominal - 2 × wall_thickness_nominal`

مثال لوله OD=110 mm و ضخامت 10 mm:

`ID_nominal = 110 - 2 × 10 = 90 mm`

این مقدار قطر داخلی هندسی اسمی است؛ قطر عبور واقعی ممکن است با تلرانس‌های ساخت تفاوت داشته باشد.

## اجرای نمونه از داخل برنامه

```powershell
python main.py
```

انتخاب کن:
- گزینه 1 در منوی اصلی
- گزینه 2 در زیرمنوی Pipe dimensional database
- Grade = PE100
- OD = 110
- SDR = 11

باید رکوردی با ضخامت اسمی 10 mm و قطر داخلی اسمی 90 mm ببینی.

## استفاده مستقیم از تابع

```python
from core.pipe_database import get_pipe_geometry

pipe = get_pipe_geometry(
    dn_od_mm=110,
    sdr=11,
    material_grade="PE100",
)
print(pipe)
```

## نکته طراحی نرم‌افزار

اگر ترکیب OD و SDR در بانک موجود نباشد، تابع خطا می‌دهد. عمداً ابعاد گمشده را حدس نمی‌زند.

## تمرین

OD=160 mm و SDR=11 را در منو جست‌وجو کن. ضخامت و قطر داخلی اسمی را یادداشت کن. سپس OD=111 mm را امتحان کن و دلیل رد شدن ورودی را توضیح بده.
