# درس ۰۱ — اجرای برنامه و شناخت main.py

## پیش‌نیاز

Python 3.10 یا جدیدتر و دریافت نسخه مخزن:

```powershell
cd A:\diameter-calc
git pull origin main
python -m pip install -r requirements.txt
```

اگر مسیر پروژه در سیستم تو متفاوت است، به‌جای `A:\diameter-calc` مسیر واقعی پوشه را وارد کن.

## اجرای برنامه

از ریشه پروژه، یعنی همان پوشه‌ای که `main.py` در آن قرار دارد، اجرا کن:

```powershell
python main.py
```

## منوی اصلی

برنامه سه بخش دارد:

1. Pipe dimensions: فهرست ابعاد موجود یا جست‌وجوی یک سایز مشخص.
2. PE material properties: مشاهده گریدهای PE و محاسبه تنش طراحی مرجع.
3. Water properties: محاسبه خواص آب شیرین یا آب دریای طبیعی.
0. Exit: خروج از برنامه.

## اجزای مهم main.py

- دستورهای `import` توابع موردنیاز را از ماژول‌های core می‌آورند.
- `read_float()` ورودی عددی را می‌گیرد و در برابر ورودی غیرعددی دوباره سؤال می‌کند.
- `print_json()` دیکشنری خروجی را خوانا نمایش می‌دهد.
- توابع `show_...` هرکدام مسئول یک بخش منو هستند.
- `main()` حلقه منوی اصلی را اجرا می‌کند.
- شرط `if __name__ == "__main__"` باعث می‌شود منو فقط هنگام اجرای مستقیم فایل شروع شود؛ اگر فایل از ماژول دیگری import شود، منو خودکار اجرا نمی‌شود.

## نکته اجرای PowerShell

کد Python را مستقیماً در خط فرمان PowerShell وارد نکن. فرمان `python main.py` را در PowerShell اجرا کن؛ خود فایل شامل کد Python است.

## تمرین

برنامه را اجرا کن، گزینه 0 را انتخاب کن و سپس دوباره اجرا کن و گزینه 1 را باز کن. مشاهده کن که برنامه چگونه از منوی اصلی وارد زیرمنوی بانک لوله می‌شود.
