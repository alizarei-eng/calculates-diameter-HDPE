# آموزش گام‌به‌گام کتابخانه مهندسی لوله HDPE

این آموزش همراه با توسعه پروژه پیش می‌رود. هر درس یک مفهوم، فایل‌های مرتبط، روش اجرا و تمرین دارد.

## مسیر درس‌ها

| درس | موضوع | خروجی مورد انتظار |
|---|---|---|
| [درس ۰۰](00-project-map.md) | شناخت معماری پروژه | درک نقش هر پوشه و فایل |
| [درس ۰۱](01-running-the-program.md) | اجرای برنامه و شناخت main.py | اجرای منوی اصلی |
| [درس ۰۲](02-pipe-database.md) | بانک ابعاد لوله | جست‌وجوی OD، SDR و محاسبه ID اسمی |
| [درس ۰۳](03-pe-materials.md) | بانک مواد PE | خواندن MRS و تنش طراحی مرجع |
| [درس ۰۴](04-water-properties.md) | خواص آب | محاسبه خواص آب شیرین و آب دریای طبیعی |

## روش مطالعه

1. ابتدا درس را از ابتدا تا انتها بخوان.
2. کد معرفی‌شده را خودت اجرا کن.
3. خروجی را با مقدار مورد انتظار مقایسه کن.
4. تمرین انتهای درس را انجام بده.
5. اگر خطا یا اختلاف دیدی، متن کامل خطا و ورودی‌ها را نگه دار.

## نکته مهم مهندسی

این نسخه ابزار بازیابی داده‌های مستند، محاسبه قطر داخلی اسمی و محاسبه خواص آب است. هنوز نرم‌افزار طراحی کامل خط لوله نیست. محاسبات هیدرولیکی، طراحی فشار، اثر دما، ضربه قوچ و بهینه‌سازی اقتصادی به نسخه‌های آینده موکول شده‌اند.
