# درس ۰۴ — کتابخانه خواص آب

## هدف

با رابط موجود برای محاسبه خواص آب شیرین و آب دریای طبیعی آشنا می‌شویم.

## آب شیرین

مدل IAPWS-IF97 برای محاسبه چگالی، ویسکوزیته دینامیکی و فشار بخار اشباع به‌کار می‌رود. فشار ورودی در API بر حسب MPa مطلق است.

## آب دریای طبیعی

مسیر آب دریا از هدایت الکتریکی درجا، دما و فشار برای محاسبه شوری عملی با PSS-78 و سپس خواص با TEOS-10/GSW استفاده می‌کند. ویسکوزیته دینامیکی از همبستگی Sharqawy et al. (2010) محاسبه می‌شود.

برای دقت بهتر شوری مطلق، مختصات جغرافیایی را هم وارد کن. اگر مختصات وارد نشود، مدل از تقریب مرجع استفاده می‌کند و هشدار مربوطه را نشان می‌دهد.

## اجرا

```powershell
python main.py
```

در منوی اصلی گزینه 3 را انتخاب کن:
- آب شیرین: دما و فشار مطلق را وارد کن.
- آب دریا: دما، فشار مطلق، EC درجا و واحد آن را وارد کن. مختصات عرض و طول جغرافیایی اختیاری‌اند، اما باید هر دو با هم وارد شوند.

## محدودیت مهم

- EC جبران‌شده به 25 درجه را به‌جای EC درجا وارد نکن.
- شورابه RO یا شورابه صنعتی را فقط از روی EC مدل نکن؛ ترکیب یونی یا مدل کالیبره‌شده لازم است.
- این بخش برای آب دریای طبیعی سازگار با PSS-78 است، نه هر نوع محلول نمکی.

## تمرین

یک بار آب شیرین را در دمای 25°C و فشار مطلق 0.101325 MPa اجرا کن. سپس مسیر آب دریا را با EC درجا و واحد mS/cm امتحان کن و خروجی و هشدارها را بخوان.
